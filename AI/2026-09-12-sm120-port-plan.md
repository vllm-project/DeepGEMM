# SM120 Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port NVIDIA's 21 SM120 kernel entry points from `origin/nv_dev` onto the `dev` (26/09) lineage, structured so future rebases onto `upstream/main` are a checklist rather than a re-port.

**Architecture:** Isolation-by-indirection. All sm120 logic lives in files named `sm120_*` that upstream never opens (Category A). Upstream-owned files (Category B) receive only mechanical 1-3 line dispatch arms, predicate widenings, and three defaulted struct fields — every extractable body is hoisted into `csrc/apis/sm120_dispatch.hpp`. A shell-based compile gate verifies every kernel on any CUDA>=13 machine without sm120 hardware.

**Tech Stack:** CUDA 13.x (nvcc), C++20, CUTLASS 4.2.1, DeepJIT (submodule), PyTorch C++ extension, Python 3 / pytest.

**Spec:** `AI/2026-09-12-sm120-port-design.md`

## Global Constraints

- **Toolkit floor: CUDA >= 13.0.** Verified: `sm_120a/120f/121a/121f` all compile block-scaled MMA correctly on 13.1, and `--gpu-architecture=sm_120a` is byte-identical to `-gencode`. Do NOT add `-gencode` handling or patch DeepJIT.
- **Language: C++20.** Use `std::format`, never `fmt::format`. `third-party/fmt` does not exist on this branch.
- **Never edit `deep_gemm/include/deep_gemm/ptx/tma.cuh`.** The one helper sm120 needs goes in `common/sm120_utils.cuh`.
- **Never change `ptx/tma.cuh` cache-hint defaults** (`EVICT_FIRST` vs `EVICT_NORMAL`) — that would silently alter sm90/sm100.
- **Every Category B edit must be recorded in `AI/sm120_touchpoints.md` in the same commit.** No exceptions.
- **Numerics are unverifiable here** (no sm120 hardware; this box is GB200/sm_100). Never claim a kernel "works" — only that it compiles and emits the expected MMA. Do not enable sm120 by default in any released artifact.
- Reference branches: source `origin/nv_dev` @ `572557e`; target `dev` @ `66081d4`; merge base `559d79f`.
- Host-side naming: `runtime->get_num_sms()`, `runtime->get_tc_util()`, `jit->device.get_arch_major()`, `jit->compile(tag, src)`, `jit->launch(kernel, options, ...)`.

**Files:**

**Interfaces:**
- Consumes: Task 1's toolkit conventions
- Produces:
  - `AI/tools/check_sm120.sh` — exit 0 iff all listed headers compile and all listed instantiations emit their expected opcode. Reads `$CUDA_HOME` (default `/usr/local/cuda`), `$SM120_ARCH` (default `sm_120a`).
  - `deep_gemm::sm120_mma::{fp8_mma, fp8_mma_block_scaled, fp8_fp4_mixed_mma_block_scaled, fp4_fp8_mixed_mma_block_scaled, fp4_mma_block_scaled, bf16_mma, tf32_mma}`
  - `deep_gemm::sm120::tensor_map_replace_global_dim_in_smem(cute::TmaDescriptor*, const uint32_t&)`

- [ ] **Step 1: Write the gate**

```bash
cat > AI/tools/check_sm120.sh <<'EOF'
#!/usr/bin/env bash
# SM120 device compile gate. Runs on ANY machine with CUDA >= 13 -- no sm120
# hardware required. nvcc cross-compiles sm_120a from any host.
#
# Verifies, for every sm120 device header:
#   1. it compiles standalone (include-graph / API-drift check)
#   2. one known-good instantiation emits the expected MMA opcode in SASS
set -uo pipefail
REPO="$(cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd)"
CUDA_HOME="${CUDA_HOME:-/usr/local/cuda}"
NVCC="$CUDA_HOME/bin/nvcc"; CUOBJDUMP="$CUDA_HOME/bin/cuobjdump"
ARCH="${SM120_ARCH:-sm_120a}"
[ -x "$NVCC" ] || { echo "FATAL: no nvcc at $NVCC (set CUDA_HOME)"; exit 2; }
WORK="$(mktemp -d)"; trap 'rm -rf "$WORK"' EXIT
INC="-I$REPO/deep_gemm/include -I$REPO/third-party/cutlass/include -I$CUDA_HOME/include/cccl"
FLAGS="-std=c++20 -cubin --gpu-architecture=$ARCH --expt-relaxed-constexpr --expt-extended-lambda -diag-suppress 177,550"
PASS=0; FAIL=0

# --- 1. standalone header compiles (one path per line)
HEADERS="$(cat "$REPO/AI/tools/sm120_headers.txt" 2>/dev/null || true)"
for h in $HEADERS; do
  [ -f "$REPO/deep_gemm/include/$h" ] || { printf '%-58s MISSING\n' "$h"; FAIL=$((FAIL+1)); continue; }
  echo "#include <$h>" > "$WORK/c.cu"
  if $NVCC $FLAGS $INC -o /dev/null "$WORK/c.cu" 2>"$WORK/e"; then
    printf '%-58s include OK\n' "$h"; PASS=$((PASS+1))
  else
    printf '%-58s include FAIL\n' "$h"; sed -n '1,6p' "$WORK/e"; FAIL=$((FAIL+1))
  fi
done

# --- 2. instantiations: each AI/tools/sm120_tu/<name>.cu has a sibling
#        <name>.expect containing a substring that must appear in the SASS
#        (empty .expect = compile-only, no MMA expected)
for tu in "$REPO"/AI/tools/sm120_tu/*.cu; do
  [ -e "$tu" ] || break
  n="$(basename "$tu" .cu)"; exp="$(cat "${tu%.cu}.expect" 2>/dev/null || true)"
  if ! $NVCC $FLAGS $INC -o "$WORK/$n.cubin" "$tu" 2>"$WORK/e"; then
    printf '%-58s inst FAIL\n' "$n"; sed -n '1,6p' "$WORK/e"; FAIL=$((FAIL+1)); continue
  fi
  sass="$($CUOBJDUMP -sass "$WORK/$n.cubin" 2>/dev/null || true)"
  if [ -z "$exp" ]; then
    printf '%-58s inst OK (no MMA expected)\n' "$n"; PASS=$((PASS+1))
  elif grep -q -- "$exp" <<<"$sass"; then
    printf '%-58s inst OK [%s]\n' "$n" "$exp"; PASS=$((PASS+1))
  else
    printf '%-58s inst BAD SASS (want %s)\n' "$n" "$exp"
    grep -oE '[QHIO]MMA[^ ]*' <<<"$sass" | sort -u | sed 's/^/    got: /'
    FAIL=$((FAIL+1))
  fi
done

echo "-----"; echo "pass=$PASS fail=$FAIL arch=$ARCH"
[ "$FAIL" -eq 0 ]
EOF
chmod +x AI/tools/check_sm120.sh
mkdir -p AI/tools/sm120_tu
printf 'deep_gemm/mma/sm120.cuh\ndeep_gemm/common/sm120_utils.cuh\n' > AI/tools/sm120_headers.txt
```

> **CORRECTED DURING EXECUTION — this step as originally planned was invalid.** The plan called

// SM120 block-scaled MMA requires CUDA 13.0+. On 12.x, nvcc's
